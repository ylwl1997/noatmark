What this checker does

It scans the file's bytes for C2PA / Content Credentials markers and tells you what it finds. This is detection, not full cryptographic verification — for a complete signature check use the official verify.contentauthenticity.org or the c2patool command-line tool.

Read this before you over-conclude

  • "C2PA found" means a manifest may be present — check it officially to see the full provenance chain (who/what created it).
  • "No C2PA found" proves nothing. Screenshots, re-encoding, resizing, and CDN optimization all strip the manifest. Absence of a marker is not evidence of human authorship.
  • Claude signs generated files (.png, .jpg, .svg) with C2PA metadata — read more on the C2PA explainer.

Deal with the text side too
