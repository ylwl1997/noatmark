The NoAtMark extension strips invisible characters from anything you copy — zero-width spaces, joiners, BOMs — so ChatGPT, Claude, and web pages never leave hidden baggage on your clipboard.

✅ Auto-clean on copy

Copy from ChatGPT, Claude, or any page — invisible characters are stripped automatically. Toggle it off anytime.

Click the toolbar icon for a quick paste-to-scan-and-clean panel.

Install in 4 steps — Chrome / Edge / Opera / Brave

All Chromium browsers use the same zip:

  1. Download the Chromium zip and unzip it to a folder.
  2. Open your browser: chrome://extensions, edge://extensions, opera://extensions, or brave://extensions.
  3. Turn on Developer mode (top-right).
  4. Click Load unpacked and select the unzipped folder.

Install in 4 steps — Firefox

Firefox uses its own package and a free developer add-on account (no fee):

  1. Download the Firefox zip and unzip it to a folder.
  2. Open Firefox and go to about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on… and select manifest.json inside the folder.
  4. Done — the NoAtMark icon appears. For a permanent install, publish free on addons.mozilla.org.

Safari needs a Mac + Xcode, so it's not included here.

Install in 2 steps — VS Code

  1. Marketplace: once verified, install straight from the VS Code Marketplace listing (search "NoAtMark Text Hygiene").
  2. Or manual: download the .vsix and run code --install-extension noatmark-text-hygiene.vsix (or Extensions → "..." → Install from VSIX).

Commands (Command Palette, Ctrl+Shift+P): NoAtMark: Clean invisible characters in selection (Ctrl+Alt+Shift+C) and Scan selection (Ctrl+Alt+Shift+S).

What it strips

  • Zero-width spaces (U+200B), joiners (U+200C/U+200D), word joiner
  • BOM (U+FEFF), soft hyphen, direction marks, combining grapheme joiner
  • Variation selectors and special spaces

Everything runs locally. No data, text, or browsing history ever leaves your device.
