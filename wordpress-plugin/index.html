Install in 3 steps — WordPress

  1. Download the plugin zip (keep it as a zip — don't unzip).
  2. In WordPress, go to Plugins → Add New → Upload Plugin and select the zip.
  3. Click Activate on NoAtMark Text Hygiene. Done — cleaning is on.

The "NoAtMark" sidebar appears in the block editor automatically. For a full-site sweep, open Tools → NoAtMark Text Hygiene and click Scan & clean all posts.

What it strips

  • Zero-width spaces (U+200B), joiners (U+200C/U+200D), non-joiner, word joiner (U+2060)
  • BOM (U+FEFF), soft hyphen (U+00AD), direction marks (U+200E/U+200F)
  • Combining grapheme joiner (U+034F), variation selectors, special spaces, non-breaking space

Everything runs inside your own WordPress install. No data or text ever leaves your server.

Ghost users — a real integration

Ghost doesn't support PHP plugins, but NoAtMark ships a dedicated Ghost integration: a zero-dependency Node script that bulk-cleans every post through the Ghost Admin API. Two ways to stay clean:

  1. Bulk clean (Admin API) — run the clean.js script to strip invisible characters from all posts' titles, excerpts, and bodies in one pass (markup-safe, --dry-run preview included).
  2. Real-time (browser extension) — install the free NoAtMark browser extension and it strips invisible characters automatically as you copy into the Ghost editor.

Both run on your side — no account, no upload.
