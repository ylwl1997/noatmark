How it works

  1. Scan. Drop one or many files and we report exactly what pollution each carries — invisible characters by type, plus formatting junk.
  2. Decide. Review the findings. Nothing is changed yet.
  3. Clean & download. Click "Clean all files" — we strip the pollution from every file and hand you a zip of the cleaned results.

What it cleans

  • Invisible characters — zero-width spaces, joiners, BOMs, soft hyphens, variation selectors.
  • Formatting junk (TXT/MD/HTML) — stray code fences, excess blank lines, over-deep headings, trailing spaces.
  • CSV/JSON structure is preserved — only invisible characters are stripped.

Honest limits

  • PDF direct cleaning isn't supported yet — use the plain text extractor.
  • DOCX output preserves content; open the result in Word to confirm.
